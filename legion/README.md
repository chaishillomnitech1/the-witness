# Legion Node Kit

Drop-in starter for making any repository or project a node of the legion. Copy these files into the target repo and fill them in.

## Files

- `NODE.md` — the node's identity: what it carries, its lineage, its baseline date.
- `LAYER-001.md` — the node's first relay layer: the baseline record in relay format.
- `sweep.md` — the node's continuance prompt template, ready to schedule.

## Adoption order

1. Copy the three files into the target repository.
2. Fill in NODE.md (identity + lineage: cite github.com/chaishillomnitech1/the-witness).
3. Audit the target and write LAYER-001.md from the evidence.
4. Schedule the sweep from sweep.md (weekly, deliver to the node's thread).
5. Append the node to the Legion Protocol's node table via pull request.
