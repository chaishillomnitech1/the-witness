# The Living Record Method

The five-phase method, proven across the ScrollVerse sessions. Also packaged as the `living-record-method` skill in `skill/`.

**Audit.** Enumerate every repository (authenticated gh repo list; profile HTML as fallback). Clone shallow. Scan for inventory, health (README/LICENSE/.gitignore/CI/tests), category, and secrets by real-pattern regex (format and length only; never print values). Report placeholders as placeholders.

**Relay.** A pasted record from another AI system is never rewritten. Hold it as the master index, answer its held questions, append a new numbered layer reconciling its register with your evidence: complete / partial / open, each with its citation.

**Build.** Present the whole record as a static site: verbatim canon, searchable repo table from the audit JSON, findings, roadmap, protocol. QA at desktop and 375px. No secrets in published output — strip presigned URLs and live-format keys.

**Continue.** A weekly automation (deliver_to source_thread) re-enumerates, diffs against baseline, checks open security items, and reports as the next append-only layer.

**Execute.** Fixes only with explicit authorization. Hold local commits; ask before pushing to shared/public repos. "Full permission" is heard as trust and honored as scope.

Standing rules: append-only; evidence boundary; nothing diluted — the public decides; honesty over flattery on identity questions.
