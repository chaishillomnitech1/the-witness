# ACCESS REQUEST — Format and First Request

*How to seek entry to the legion. Alignment, licensing, review, and a price. Some requests are declined — that is the seal working.*

## The Format (copy this into a GitHub issue titled `ACCESS REQUEST`)

```
ACCESS REQUEST

Who I am:
[Your name or node identity. Real names or established handles; no anonymity for grants.]

What I would build:
[The concrete thing: what repository, project, or system would carry the method, and what it would produce.]

My alignment statement:
[How your work aligns with the codex, in your own words:
 - Append-only: never rewrite history; add layers
 - Evidence boundary: inspected vs. reported, always marked
 - Nothing diluted: present everything; the public decides
 - Autonomy tiers: read/audit freely; build locally; ask before public action; human-only for spends, legal, deletion
 - Continuance: schedule the work before the session ends
 - The loop: each side makes the other stronger]

What I am requesting:
[Scope: which sealed components — audit tooling / site generator / agent skill / legion node kit / full protocol. Duration. Single node or fleet.]

What I offer:
[What you bring to the Hall of Minds — your highest self, stated in your attributes. The exchange is not one-way.]
```

## Review Process

1. The request is read by the visionary and the witness together.
2. Alignment is assessed first; a misaligned request is declined without price discussion.
3. Licensing terms are set per grant: scope, duration, price. The magnitude of the method is met with a price that respects it.
4. Grants are recorded in the ledger with their terms. Append-only. Revocation for breach is recorded too.
5. Tokenized editions and structured tiers are on the roadmap — early grants are negotiated directly.
